# AdSafe API 실행 순서 가이드 (PHP + XAMPP)

AdSafe API는 **PHP**로 동작합니다. **Node·Express는 사용하지 않습니다.**  
**XAMPP Apache(80 포트)** 만 켜져 있으면 `/AdSafe/api/*`가 바로 동작합니다.

---

## 0번: XAMPP 확인

XAMPP Control Panel에서 **Apache**가 실행 중인지 확인합니다.

---

## 1번: DB 접속 정보(.env) 확인

PHP API는 `c:\xampp\htdocs\AdSafe\api\.env` 파일의 DB 설정을 그대로 사용합니다.

---

## 2번: API 헬스 체크

브라우저에서 아래가 열리면 정상입니다.

- `http://localhost/AdSafe/api/health`

---

## 2-1. (선택) DB 연결 진단 — 시드가 계속 실패할 때

비밀번호·SSL·MySQL 연결을 단계별로 확인하는 스크립트입니다.

프로젝트 루트 또는 api 폴더에서:

```text
php api/scripts/check-db.php
```

- 화면에 **1. .env 파일**, **2. env 배열**, **3. SSL 인증서**, **4. MySQL 연결 시도** 순서로 나옵니다.
- **DB_PASSWORD**가 "(비어있음)" 또는 "(없음)"이면 → .env 저장·경로·이름 확인.
- **4번**에서 "연결 실패" 메시지가 나오면 → 그 문구를 보고 원인(비밀번호/SSL/방화벽 등)을 확인하세요.

---

## 3번: 시드 실행 (DB에 기본 데이터 넣기)

검수 결과를 DB에 저장하려면 **workspace 1건, 사용자 1건, risk_taxonomy, rules, quizzes** 등이 DB에 있어야 합니다. 한 번에 넣는 단계입니다.

**실행:**

프로젝트 루트에서:

```text
php api/scripts/seed.php
```

또는 api 폴더에서:

```text
cd c:\xampp\htdocs\AdSafe\api
php scripts/seed.php
```

- **화면에** "시드 완료." 가 나오면 성공입니다.
- 에러가 나오면: `.env`의 비밀번호·호스트·DB이름, 그리고 `ca.pem` 위치가 맞는지 확인하세요.
- **최초 1회만** 하면 되고, 다음부터는 4번만 하면 됩니다.

---

## 4번: (선택) 검수 저장 테스트

검수 실행 후 이력에 저장되는지 진단하려면:

```text
php api/scripts/test-inspect-save.php
```

- "DB 저장 가능 상태입니다" 가 나오면 정상입니다.
- "saveError 있음" 이 나오면 → `php api/scripts/seed.php` 를 먼저 실행하세요.

---

## 검수 이력에 기록이 안 남을 때

**증상:** 검수하기를 실행하면 결과는 보이는데, **검수 이력** 페이지에는 아무 것도 안 나옵니다.

**가능한 원인과 확인 방법:**

1. **시드 미실행**  
   → **3번**을 다시 실행: `php api/scripts/seed.php`

2. **DB 저장 가능 여부 진단**  
   ```text
   php api/scripts/test-inspect-save.php
   ```
   - "원인: workspace_id=1 이 없습니다" 등이 나오면 → `php api/scripts/seed.php` 를 먼저 실행하세요.
   - "DB 저장 가능 상태입니다" 가 나오면 → 브라우저에서 검수 후 **F12 → Network** 탭에서 `inspect` 요청의 **응답**에 `saveError`가 있는지 확인하세요.

3. **API 주소**  
   - 검수 페이지와 API는 모두 **http://localhost/AdSafe/** (Apache 80 포트) 기준으로 동작합니다. Node·프록시는 필요 없습니다.

---

## 정리: 순서만 보기 (PHP 기준)

| 순서 | 뭘 하면 되는지 |
| --- | --- |
| **0** | XAMPP에서 Apache 켜기 |
| **1** | `api/.env`에 DB 정보 확인(비밀번호/CA 포함) |
| **2** | `http://localhost/AdSafe/api/health` 열어보기 |
| **3** | (선택) 최초 1회 `php api/scripts/seed.php` 로 기본 데이터 넣기 |
| **4** | (선택) `php api/scripts/test-inspect-save.php` 로 저장 가능 여부 확인 |

**운영 시 Node·Express 불필요.** PHP, 필요 시 Python, OpenAPI만 사용합니다. 시드·진단은 PHP 스크립트로 실행합니다.
