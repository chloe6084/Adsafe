# AdSafe API 실행 순서 가이드 (PHP)

AdSafe API는 **PHP 단일 스택**으로 동작합니다. Node.js는 필요 없습니다.

---

## 0번: 서버 실행

### 방법 A: XAMPP
XAMPP Control Panel에서 **Apache**를 시작합니다.

### 방법 B: PHP 내장 서버
프로젝트 루트(`c:\xampp2\htdocs\AdSafe`)에서 `start-server.bat` 더블클릭,  
또는 명령 프롬프트에서:

```text
cd c:\xampp2\htdocs\AdSafe
c:\xampp2\php\php.exe -S 0.0.0.0:8080 -t . router.php
```

---

## 1번: DB 접속 정보(.env) 확인

`api/.env` 파일에 Aiven MySQL 정보가 있는지 확인합니다.

---

## 2번: API 헬스 체크

브라우저에서 아래가 열리면 정상입니다.

- XAMPP: `http://localhost/AdSafe/api/health`
- PHP 내장 서버: `http://localhost:8080/api/health`

---

## 2-1. (선택) DB 연결 진단

비밀번호·SSL·MySQL 연결이 어디서 막히는지 확인하려면:

```text
cd c:\xampp2\htdocs\AdSafe\api
c:\xampp2\php\php.exe scripts/check-db.php
```

---

## 3번: 시드 실행 (DB에 기본 데이터 넣기, 최초 1회)

```text
cd c:\xampp2\htdocs\AdSafe\api
c:\xampp2\php\php.exe scripts/seed.php
```

"시드 완료." 메시지가 나오면 성공입니다.

---

## 검수 이력에 기록이 안 남을 때

1. **시드 미실행** → 3번을 실행: `php scripts/seed.php`
2. **DB 저장 가능 여부 진단**:
   ```text
   c:\xampp2\php\php.exe scripts/test-inspect-save.php
   ```
   - "DB 저장 가능 상태입니다" → DB 정상.
   - "workspace_id=1 이 없습니다" → `php scripts/seed.php` 먼저 실행.

---

## 정리: 순서만 보기

| 순서 | 뭘 하면 되는지 |
| --- | --- |
| **0** | 서버 실행 (XAMPP Apache 또는 `start-server.bat`) |
| **1** | `api/.env`에 DB 정보 확인 |
| **2** | 헬스 체크 URL 열어보기 |
| **3** | (최초 1회) `php scripts/seed.php` 로 기본 데이터 넣기 |

**Node.js 불필요** — PHP만으로 모든 API·시드·진단이 동작합니다.
