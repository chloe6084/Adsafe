# 회의 진행상황

실행 전 아젠다(`meetings/agenda/`)에서 논의한 회의의 **진행상황·결론·결정 사항**을 정리하는 폴더입니다.

---

## 용도

- 회의 후 **결정 사항** 요약
- **다음 액션** 상태 (완료/진행 중/대기)
- **결론 반영** 문서 (아젠다 문서를 수정하기보다, 여기에 "2026-02-XX 회의 결과" 형태로 보관)

---

## 파일 네이밍 예시

- `검수이력_DB관리_회의결과_20260213.md` — 아젠다 대응 회의 결과
- `광고데이터_자산화_회의결과_YYYYMMDD.md` — 별도 회의 시

회의가 끝나면 해당 아젠다에 맞는 진행상황 문서를 이 폴더에 추가하면 됩니다.
