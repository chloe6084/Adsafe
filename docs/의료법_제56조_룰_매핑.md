# 의료법 제56조 ②항 금지유형 ↔ AdSafe 룰 매핑

> 의료법 제56조 ②항에 따른 금지 유형과 AdSafe 검수 룰의 대응 관계를 정리한 문서입니다.

---

## 매핑 표

| 법 조항 (금지 유형) | AdSafe 리스크 코드 | 비고 |
|---------------------|---------------------|------|
| 치료효과 오인 유발 / 치료경험담(후기) 활용 금지 | RISK_GUARANTEE_RESULT, RISK_GUARANTEE_* / RISK_EXPERIENCE_REVIEW, RISK_EXPERIENCE_BEFORE_AFTER, RISK_EXPERIENCE_NARRATIVE | 효과 단정, 후기·전후 사례 |
| 거짓 내용 표시 금지 (근거 없는 수치/효과/자격/장비 등) | RISK_FALSE_NUMERIC, RISK_UNVERIFIED_CREDENTIAL, RISK_UNVERIFIED_EQUIPMENT, RISK_PRICE_DECEPTIVE | 허위 수치·인증·장비·가격 기만 |
| 비교 우위 표현 금지 | RISK_SUPERLATIVE_ABSOLUTE, RISK_SUPERLATIVE_RANK, RISK_SUPERLATIVE_FIRST, RISK_COMPARISON_OTHER, RISK_COMPARISON_METHOD | 최고/1등/유일/타 병원 비교 |
| 비방 금지 | RISK_COMPARISON_DISPARAGE | 타 기관 비하 |
| 시술행위 직접 노출(수술 장면 등) 금지 | (텍스트 검수 범위 밖) | 이미지·영상 검수 시 별도 검토 |
| 중요정보(심각 부작용 등) 누락 금지 | RISK_GUARANTEE_ZERO_RISK, RISK_GUARANTEE_CERTAINTY | 부작용 없음 단정, 100% 등 |
| 객관적 사실 과장 금지 | RISK_GUARANTEE_*, RISK_SUPERLATIVE_*, RISK_DURATION_* | 확실/즉각/완벽/무조건 등 |
| 법적 근거 없는 자격·명칭 표방 금지 | RISK_QUALIFICATION_FALSE, RISK_QUALIFICATION_MIXED, RISK_QUALIFICATION_TITLE, RISK_UNVERIFIED_CREDENTIAL | 인증/공인/명의 등 |
| 기사/전문가 의견 형태 포장 광고 금지 | (1차 룰 범위 밖) | 문맥 판별 필요 |
| 심의 대상 광고를 심의 없이/다르게 게재 금지 | (현재 스코프 밖) | 심의필 메타데이터 검증 |
| 비급여 진료비용 할인/면제를 오인하게 하는 방식 금지 | RISK_INDUCEMENT_DISCOUNT, RISK_INDUCEMENT_CONDITION, RISK_PRICE_EXCESSIVE, RISK_PRICE_DECEPTIVE | 할인·이벤트 조건·기간·추가비용 단정 |
| 인증·보증·추천 표현(상장/감사장 포함) 제한 | RISK_QUALIFICATION_*, RISK_INSURANCE_GUARANTEE | 인증/보증/추천 |
