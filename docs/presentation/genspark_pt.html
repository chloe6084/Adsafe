📺 2분 데모 시나리오 (상세)

1 로그인 (마케터 계정)
클릭 순서: login.html → 이메일/비밀번호 입력 → "로그인" 버튼
보여줄 포인트: Editor 권한으로 로그인, 메인 대시보드 진입
2 검수 시작
클릭 순서: 상단 메뉴 "검수하기" → adsafe.html 진입
보여줄 포인트: 광고 유형 선택 (선택 사항), 광고 제목 입력 (선택 사항)
문구 입력: "최고의 병원, 완치 보장, 50% 할인 이벤트" → "검수하기" 버튼 클릭
3 검수 결과 확인
보여줄 포인트:
• 요약 위험도: 높음 (high)
• 총 적발 건수: 2건
• 적발 1: RISK_SUPERLATIVE_ABSOLUTE — "최고" 매칭 (위험도: 높음)
• 적발 2: RISK_GUARANTEE_RESULT — "완치 보장" 매칭 (위험도: 높음)
• 각 적발에 법령 근거, 설명, 수정 가이드 표시
강조: 응답 시간 ~500ms 실측
4 수정 가이드 확인
보여줄 포인트:
• "최고" → 삭제 또는 구체적 수치로 대체 (예: "10년 경력")
• "완치 보장" → 삭제 (치료 결과 단정 표현 금지)
• 각 가이드는 법령 조문과 1:1 매핑된 근거 기반
5 검수 이력 조회
클릭 순서: 상단 메뉴 "검수 이력" → inspection-history.html
보여줄 포인트: 이전 검수 기록 목록, 필터 기능 (광고 유형, 위험도, 날짜), 페이징, "상세보기" 클릭 시 inspection-detail.html로 이동해 전체 적발 내역 재확인 가능

💬 예상 Q&A (8개)

Q1: 검수 정확도는 어떻게 검증했나요?
MVP 단계에서는 의료법 제56조 기반 3개 리스크코드와 11개 키워드 샘플로 구성된 룰셋을 적용했습니다. 정확도 검증은 실제 의료광고 샘플 테스트를 통해 진행 중이며, 향후 실무 사례 데이터를 축적해 정밀도를 개선할 예정입니다. 현재는 참고용 도구이며, 최종 판단은 사용자 책임입니다.
Q2: 법적 책임은 누가 지나요?
AdSafe는 참고용 자동 검수 도구이며, 검수 결과에 법적 효력은 없습니다. 최종 광고 집행 및 규제 준수에 대한 책임은 사용자(광고주 또는 대행사)에게 있습니다. 필요시 공식 심의 기관에 문의하시기 바랍니다.
Q3: 법령이 개정되면 어떻게 대응하나요?
로드맵 Phase 1에서 관련 법령 페이지를 매일 1회 크롤링해 개정을 자동 감지하고, Slack으로 알림을 보낼 예정입니다. 감지된 변경 사항은 관리자가 Admin 모드에서 리스크코드와 룰셋을 직접 업데이트하며, 버전 관리 시스템을 통해 이력을 추적합니다.
Q4: 단순 키워드 매칭이라면 우회가 가능하지 않나요?
맞습니다. 현재는 keyword와 regex 방식으로 작동하며, 의도적 띄어쓰기나 동의어 우회는 탐지하기 어렵습니다. 이는 MVP 한계이며, 향후 NLP 기반 의미 분석 및 동의어 사전 확장으로 고도화할 계획입니다. 하지만 법령 기반 근거와 감사 추적성은 단순 AI 방식보다 훨씬 우수합니다.
Q5: 확장성—다른 업종에도 적용 가능한가요?
기술적으로는 가능합니다. 리스크 분류 체계와 룰셋 구조는 다른 규제 업종(금융, 식품 등)에도 적용할 수 있습니다. 다만 각 업종별 법령 해석과 데이터 자산화 작업이 필요하므로, 당장은 의료광고에 집중하고 추후 확장을 검토할 예정입니다.
Q6: 운영성—룰을 계속 업데이트하는 데 비용이 얼마나 드나요?
Admin 모드를 통해 관리자가 직접 룰과 버전을 관리할 수 있어, 외부 의뢰 비용은 들지 않습니다. 법령 모니터링 자동화(Phase 1)를 구현하면 대부분의 업데이트는 시스템이 감지하고, 관리자는 변경 사항을 검토 후 반영하는 방식으로 운영 부담을 최소화할 수 있습니다.
Q7: 경쟁 서비스 대비 차별점은 무엇인가요?
대부분의 경쟁 서비스는 LLM 기반 확률적 응답이거나, 단순 키워드 필터 수준입니다. AdSafe는 의료법 제56조 조문을 직접 해석해 리스크코드와 룰셋으로 자산화했으며, 근거성·재현성·감사추적성이 보장됩니다. 또한 Admin 모드를 통해 팀 내부에서 룰을 직접 관리할 수 있어 운영 자율성이 높습니다.
Q8: 현재 실제 사용자가 있나요?
MVP 단계로, 현재는 부트캠프 개인 프로젝트입니다. 실제 의료기관 또는 광고 대행사를 대상으로 파일럿 테스트를 진행할 계획이며, 피드백을 통해 룰셋과 기능을 고도화한 뒤 정식 서비스로 전환할 예정입니다.
