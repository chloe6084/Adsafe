# AdSafe 발표자료

투자자·창업지원사업 심사위원 대상 10분 발표용 HTML 발표자료입니다.

## 사용 방법

1. **브라우저에서 열기**  
   `AdSafe_presentation.html` 파일을 더블클릭하거나, 브라우저로 드래그하여 엽니다.

2. **로컬 서버로 열기 (선택)**  
   프로젝트 루트에서:
   ```bash
   # 예: PHP 내장 서버
   php -S localhost:8080 -t docs/presentation
   ```
   브라우저에서 `http://localhost:8080/AdSafe_presentation.html` 접속.

## 조작

- **슬라이드 이동**: 상단 화살표(‹ ›) 또는 키보드 **←** **→**
- **특정 슬라이드**: 상단 점(dots) 클릭
- **스크롤**: 마우스 휠로도 슬라이드 간 이동 가능 (scroll-snap)

### 실제 화면이 보이게 하려면

4·7·8번 슬라이드의 iframe에 **실제 AdSafe 페이지**가 뜨려면, 발표자료를 **웹 서버 경로**로 열어야 합니다.

- **권장**: XAMPP Apache 실행 후 브라우저에서  
  `http://localhost/AdSafe/docs/presentation/AdSafe_presentation.html`  
  로 접속.
- 파일을 더블클릭해 `file://` 로 열면 iframe은 보안상 빈 칸일 수 있습니다. 그때는 슬라이드 안의 **「새 탭에서 열기」** 링크로 실제 화면을 보여주면 됩니다.

## 로고·CI

- `logo_adsafe.svg`: 상단 로고/CI용 SVG (실드 아이콘 + AdSafe 워드마크)
