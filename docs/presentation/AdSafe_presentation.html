의료·광고 규제 리스크 관리

검수 · 학습 · 안전한 문구 생성까지, 한 플랫폼에서

1

왜 필요한가

의료 광고는 의료법 제56조 및 심의 가이드라인에 따라 과장·허위·오인 유발 표현이 엄격히 제한됩니다.

  • 효과 단정, 최상급 표현, 할인·이벤트 조건 생략 등 한 건의 위반만으로도 과태료·행정처분 위험
  • 담당자마다 규정 해석이 달라 사전 검토 부담과 실수 가능성 존재
  • 규정을 몰라 위반한 경우와 악의적 위반을 구분하기 어려움 → 검증 가능한 사전 점검 도구 수요

기회: 의료기관·마케팅 에이전시가 광고 문구를 게재 전에 빠르게 점검하고, 직원이 규정을 학습할 수 있는 올인원 플랫폼

2

AdSafe가 하는 일

광고 문구를 입력하면 룰 엔진이 의료법·가이드라인 기준 리스크를 검출하고, 「검증 필요」 항목을 알려줍니다. 위반 확정이 아닌, 사전 점검·보완용입니다.

광고 문구 입력 → 전처리·정규화 → 룰 엔진 검수 → 리스크·개선안 안내

검수 이력 저장, 학습 모듈, AI 문구 생성까지 하나의 서비스로 제공합니다.

룰 엔진 구조

텍스트 전처리(정규화) 후, 리스크 택소노미 기반 룰을 키워드·정규식으로 적용합니다.

  • 입력 → 원문 정규화(공백·특수문자 등)
  • 룰 → riskCode, level1/2/3(과장표현·효과보장·가격·유인·자격 등), keywords + regex
  • 매칭 → 키워드 포함 여부 + 정규식 매칭(할인율 50% 이상, 극단 수치+성과지표 근접 등)
  • 출력 → findings(riskCode, riskLevel, matchedText, explanation, suggestion)

PHP 서버 룰 엔진 + JSON 룰 데이터. 필요 시 DB 기반 룰로 확장 가능하며, 「검증 필요」 톤의 설명·제안 문구를 제공합니다.

9

룰 엔진 — 리스크 택소노미 예시

의료법·가이드라인에 맞춘 리스크 코드로 구분해 검출합니다.

대분류 (level1) 중분류 (level2) 리스크 코드 예시
과장표현최상급·순위·최초RISK_SUPERLATIVE_ABSOLUTE, RISK_SUPERLATIVE_RANK
효과보장결과 단정·무위험·100%RISK_GUARANTEE_RESULT, RISK_GUARANTEE_ZERO_RISK
가격·유인할인·조건·과도 할인RISK_PRICE_EXCESSIVE, RISK_INDUCEMENT_CONDITION
자격·거짓표시인증·장비·허위수치RISK_UNVERIFIED_CREDENTIAL, RISK_FALSE_NUMERIC

각 룰별 explanation·suggestion을 제공해, 수정 방향까지 안내합니다.

10

의료법 제56조 ②항과의 대응

규제 근거를 명확히 하여, 심사·투자 관점에서 법적 기반을 보여줍니다.

금지 유형 (의료법 제56조 ②항) AdSafe 룰 대응
치료효과 오인 / 경험담 활용 금지RISK_GUARANTEE_*, RISK_EXPERIENCE_*
거짓 내용 표시 (수치·자격·장비·가격)RISK_FALSE_NUMERIC, RISK_UNVERIFIED_CREDENTIAL, RISK_PRICE_DECEPTIVE
비교 우위·비방 금지RISK_SUPERLATIVE_*, RISK_COMPARISON_*
부작용 누락·과장 금지RISK_GUARANTEE_ZERO_RISK, RISK_GUARANTEE_CERTAINTY
할인·면제 오인 금지RISK_INDUCEMENT_*, RISK_PRICE_EXCESSIVE, RISK_PRICE_DECEPTIVE
인증·보증·추천 제한RISK_QUALIFICATION_*, RISK_INSURANCE_GUARANTEE

AdSafe는 「위반 확정」이 아닌 「검증 필요」 플래그로 운영합니다.

기술 구성

백엔드

  • PHP (XAMPP Apache) — 검수 API, AI 문구 생성, 퀴즈·사용자 API
  • Aiven MySQL — 검수 이력, 워크스페이스·사용자, 룰·택소노미
  • 룰 데이터: JSON fallback + DB 확장 가능

프론트

  • HTML/CSS/JS, Bootstrap 5 — 반응형 UI
  • 검수·이력·학습 대시보드·어드민 콘솔

주요 API

  • POST /api/inspect — 문구 검수 (summary, findings)
  • GET /api/inspection-history — 검수 이력 목록·상세
  • AI 문구 생성·퀴즈·인증 등 REST API
